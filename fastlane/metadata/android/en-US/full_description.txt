OMINOY is an open-source Android emulator based on Libretro, focused exclusively on Nintendo Game Boy, Game Boy Color, and Game Boy Advance. It is designed to provide a simple, integrated experience on phones and Android TV. It is free and has no ads.

Supported systems:
- Game Boy (GB)
- Game Boy Color (GBC)
- Game Boy Advance (GBA)

Features:
- Automatically save and restore game saves and states
- ROM scanning and library indexing
- Optimized, customizable touch controls
- Quick save/load with slots
- Support for ZIP-compressed ROMs
- LCD/CRT display simulation
- Fast-forward support
- Gamepad support and local multiplayer
- Tilt input
- Cloud save sync in supported builds
- Custom per-game thumbnails for ROM hacks and homebrew
- No ads

This application does not contain any games. You need to provide your own legally owned ROM files.
