# Touch control appearance

Use **Edit controls** in the game menu to adjust button opacity and background
style. **Settings → Shared touch control appearance** provides shared defaults
for size, opacity and button backgrounds. Disable **Use shared appearance** in
the editor to keep a system's own appearance.

Layouts are saved by system, controller layout and orientation. Existing layouts
keep their settings; reset reconnects the current layout to the shared defaults
without changing other layouts. Position, margins and rotation stay local.

The transparent button background style builds on
[#1163](https://github.com/Swordfish90/Lemuroid/pull/1163) by nikhilCad.
